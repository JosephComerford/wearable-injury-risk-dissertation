# Wearable Injury Risk Dissertation

Code supporting an MSc Data Science dissertation investigating whether wearable-derived health and running data can identify patterns associated with injury risk.

## Repository structure

- `src/` – data collection and preprocessing scripts
- `notebooks/` – exploratory analysis, anomaly detection and classification notebooks
- `data/` – documentation only; raw wearable data is excluded
- `results/figures/` – selected non-sensitive figures for the dissertation

## Data privacy

Raw Garmin and participant-derived datasets are not included in this repository. Authentication tokens and generated Garmin reports are excluded using `.gitignore`.

## Status

Repository currently being prepared for dissertation submission.
