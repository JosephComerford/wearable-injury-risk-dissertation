# Data

This directory contains the processed datasets and example 30-day samples required to reproduce the analyses included in this repository.

## Included Files

- `Report Sample 31 (Injured).csv` – injured 30-day sample used by the single-sample exploratory analysis notebook.
- `Report Sample 8 (Healthy).csv` – healthy 30-day sample provided as an alternative example for the single-sample exploratory analysis.
- `Combined Data VF.ods` – daily multi-sample dataset used by the anomaly detection analysis.
- `Trend Data Combined.ods` – processed sample-level dataset used by the supervised classification notebooks.

The notebooks are configured to access these files from this `data/` directory.

## Privacy

Only the datasets required to reproduce the dissertation analyses are included.

Garmin authentication credentials, authentication tokens and other locally generated Garmin reports are not included and must not be committed to the repository.

The supplied data should be used only in accordance with the data handling and ethical requirements applicable to the dissertation.
